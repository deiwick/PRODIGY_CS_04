# Keylogger Project

## 📌 Overview
This project is a **Python-based keylogger** developed for **educational and cybersecurity research purposes only**.  
It demonstrates how keystroke logging works at a technical level, helping learners understand both the risks and defensive measures against such attacks.

⚠️ **Disclaimer:**  
This tool is intended strictly for **learning, testing, and authorized environments**.  
Do **not** use it for malicious purposes. Unauthorized use may violate privacy laws and ethical guidelines.

---

## ✨ Features
- Logs all keystrokes pressed on the keyboard
- Stores logs in a local file for analysis
- Timestamped entries for better tracking
- Lightweight and runs in the background
- Can be extended with email/remote log sending (optional)

---

## 🛠️ Installation & Usage
### Requirements
- Python 3.x
- `pynput` library (for keyboard event handling)
